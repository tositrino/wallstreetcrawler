# walstreetcrawler

crawl reddit channel workstreetbit and counts occurrence of stock symbols in posts. 
This would give an observer a hint which stock currently is discussed in the community
and therefore might be worth looking at.

Based on a similar idea for a news attention system in 2020 and the heise articles [1],[2]
but the code ist mostly done w/o claude ;-)
